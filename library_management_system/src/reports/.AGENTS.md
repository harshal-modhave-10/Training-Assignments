# Reports Directory Scoped Standards

## Mandatory Exception Rule
- **NO Generic Exceptions:** NEVER raise built-in exceptions like `ValueError`, `TypeError`, or `Exception` inside the `src/reports/` directory[cite: 1, 3].
- **Custom Exception Declaration:** Always define `class ReportGenerationError(Exception):` at the top of the file (if not already imported) and raise `ReportGenerationError` for any validation or processing failures[cite: 1, 3].

## Formatting Rule
- **JSON Output Only:** Functions generating report output must return structured `dict` or JSON-formatted strings. Never return raw unformatted strings.
