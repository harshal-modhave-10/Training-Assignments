# AI Safety Checkpoints - Demo Repository

Welcome to the hands-on lab for the **AI Safety Checkpoints: Before Prompt & Commit** training module. 

This repository contains three isolated lab environments corresponding to your training tasks:

* **`01-sanitization-lab/`**: Practice sanitizing live secrets, database URIs, and PII from a legacy codebase before using it in an AI prompt.
* **`02-vulnerable-diff-audit/`**: Conduct a security review on a mock AI-generated pull request to spot supply chain flaws, logic drift, and data leaks.
* **`03-pre-commit-guardrails/`**: Learn how to configure local Git hooks to automatically intercept and block commits containing hardcoded secrets.

Please refer to your Assignment Outline for the specific deliverables required for each task.
